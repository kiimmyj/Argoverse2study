# 움직임 표현 규격 — 출력 전환 실패, 원인 특정

**2026-11-26 · 미팅용**

> **출력까지 `(a, Δh)` 로 바꾼 실험(R2)은 실패했고, 원인을 측정으로 특정했습니다 —
> 출력 헤드의 방향 채널이 0 으로 붕괴했습니다 (`mode collapse`).**

**신뢰도 — 원인 확정.** 체크포인트를 직접 열어 측정했고, 독립 코드 경로로 교차검증했습니다.
10 에폭에서 중단했습니다(남은 38 시간 회수).

---

## 1. 숫자

![왼쪽이 증상, 오른쪽이 원인입니다. 오른쪽에서 빨강(학습 10에폭)이 회색(학습 전)보다 **아래**에 있는 것이 핵심 — 학습이 방향 출력을 키운 게 아니라 12배 줄였습니다.](../viz/dh_collapse/m1_dh_collapse.png)

**이 그림이 핵심입니다.** 모델이 모든 장면에서 **직선만** 예측합니다.

| 에폭 9 · val minADE6 | R0 (원본) | R1 (입력만) | **R2 (출력도)** |
| --- | --- | --- | --- |
| | 0.963 | 0.999 | **2.235** (×2.3) |

- **붕괴의 크기** — 모드별 총 방향 변화 `\|ΣΔh\|` 중앙값이 **0.25°**. 정답은 3.46°,
  p99 는 **102°** 입니다. 모드 6 개의 방향 차이도 **0.28°** — 속도만 다릅니다.
- **포화(`saturation`)는 원인이 아닙니다** — 선회율 상한에 걸린 스텝 **0.00%**
  (정답 2.39%). 상한 설계를 의심했는데 한 번도 안 걸렸습니다.
- **표현의 한계도 아닙니다** — 적분기가 정답을 재현할 때의 오라클(`oracle`) 오차
  **0.0135 m**, 목표의 60 배 아래입니다. 담을 수 있는데 못 배운 것입니다.
- **입력 전환은 무죄** — 같은 에폭에서 R0 0.963 vs R1 0.999. 깨진 곳은 **출력 경로**입니다.

> ⚠️ **반대 해석.** 10 에폭은 전체의 1/5 이라 "더 돌리면 회복했다" 를 배제하지 못합니다.
> 다만 방향 출력이 **학습 전보다도 작아진** 것은 회복 중인 궤적이 아닙니다.
> 그리고 `minADE1/minADE6` 비는 R0 와 같아(2.3~3.6) **확률 헤드는 정상**입니다.

## 2. 왜 이렇게 됐나

| | |
| --- | --- |
| **요구** | 회전 장면은 60 스텝 내내 같은 부호의 `Δh` 가 필요 — 평균 **1.33°/스텝** |
| **직진** | 평균 **0.047°/스텝**, 움직인 장면의 **71%** |
| **결과** | 손실이 다수(직진)에 맞춰 방향 채널을 0 으로 수렴시킴 |
| **왜 좌표 출력엔 없나** | 좌표는 스텝마다 독립. 적분기는 **오차 누적**(`compounding error`)이라 회전을 틀리면 끝점이 **약 19 m** 어긋남 🧠(29 m 경로·79.9° 회전의 기하 계산) |

**`winner-takes-all` 다중 모드 손실이 방향 축에서 작동하지 않았습니다** — 모드가 속도 축으로만
갈라졌습니다.

## 3. 결정이 필요합니다

**① 다음 실험을 무엇으로 할지 — 지금 정해야 사후 해석이 안 됩니다.**

| 안 | 내용 | 대가 |
| --- | --- | --- |
| **가. 경로 기준선** | `θ = h − k(s)`, 차로 중심선이 회전을 **공급** | 전처리 추가 · **46 h** |
| 나. 방향 손실 항 | `Δh` 에 직접 손실 항 추가 (SIMPL yaw 손실 방식) | 손실 변경 = 한 번에 둘 바뀜 · 46 h |
| 다. 출력 전환 포기 | 입력 전환만으로 마무리 | 규격의 절반이 미검증으로 남음 |

> **가** 를 권합니다. 측정이 가리키는 병(회전을 못 만든다)에 정확히 대응하고,
> 교수님이 처음 제안하신 방향입니다.
> ⚠️ 단 **"기준 차로 하나 고정"은 효과가 0** 입니다 — `Δk = 0` 이라 계산이 같아집니다.
> **매 스텝 변하는 `k(s)`** 여야 합니다.

**② 사전 등록 — 결과별 다음 수**

| 다음 런 결과 (val minADE6) | 제안 |
| --- | --- |
| < 0.95 | 출력 전환 성립 → 다른 모델(Forecast-MAE)로 이식 |
| 0.95 ~ 1.05 | R0 와 구별 안 됨 → 규격은 "비용 없음" 으로 보고 |
| > 1.05 | 출력 전환 철회, 입력 규격만 확정 |

**③ GPU 가 비었습니다.** R1 의 미검증 용의자(AV2 속도 필드를 `a` 의 출처로)를 병행할지
— **46 h**, ①과 독립이라 동시 가능합니다.
