# 규격화 — 차의 움직임을 좌표 대신 「무엇을 했나」로 적는다

**2026-11-26 · 미팅용**

> **좌표 `(x, y)` 대신 움직임 `(a, h)` 로 적는 방법을 **규격 하나**로 못 박았습니다.
> 다른 모델에도 같은 방식으로 붙고, 설계 상수는 **전부 기존 논문의 값**입니다.**

**신뢰도 — 규격은 확정, 효과는 미확정.** 입력만 바꾼 R1 은 **졌고**(0.795 → 0.830),
출력까지 바꾼 R2 가 **지금 돌고 있습니다.**

---

## 1. 무엇을 규격화했나

![왼쪽이 원본, 오른쪽이 규격입니다. 바뀌는 자리는 양끝 두 군데뿐이고 모델 속은 그대로입니다.](../viz/r1_analysis/m_lang.png)

- **`a`** 속도를 얼마나 올렸나/내렸나 · **`h`** 어느 쪽을 향해 가나 · **`Δh`** 방향을 얼마나 틀었나
- **입력** — 움직임 **6칸(`Δx, Δy` + 차체각 + 속도벡터) → 3칸(`a, cos h, sin h`)**
- **출력** — 모델이 매 스텝 **`(a, Δh)`** 를 내고, **학습 파라미터가 0인 수식**이 좌표로 되돌립니다

> **왜.** 좌표는 *"어디 있었나"* 라 같은 운전도 차가 북쪽을 보면 다른 숫자, 동쪽을 보면 또
> 다른 숫자입니다. `(a, h)` 는 *"무엇을 했나"* 라 **방향이 달라져도 같습니다.**

---

## 2. 차선을 출력에서 뺀 이유

![오른쪽 아래가 핵심입니다. 초록(매 스텝 차로를 다시 잡음)은 차로가 바뀌는 순간 한 스텝에 12° 튑니다. 빨강(차로 하나 고정)은 매끄럽고, 그 값이 곧 Δh 자체입니다.](../viz/meeting_1029/m7_frenet_baseline.png)

**① 매 스텝 다시 잡으면 자가 움직입니다.** 차는 매끄럽게 도는데 *"가장 가까운 차로"* 가
바뀌는 순간 기준이 점프합니다 — val 전수 **한 스텝 32.7°**. 신호의 거칠기가 **0.76° →
7.81°** 로 10배가 됩니다.

**② 그리고 순환입니다.** 미래 차로를 알려면 미래 위치를 알아야 하는데, 그게 맞히려는 것입니다.

**③ 고정하면 차선이 계산에서 사라집니다.** 각도가 아니라 **변화량**을 내니, 기준이 안
움직이면 변화량에 기준이 안 들어갑니다 — *집에서 회사까지 몇 미터 갔나는 기준점을 어디로
잡든 같습니다.* **「차로 고정」과 「차로 안 씀」이 같은 계산**입니다.

## 3. 설계 상수는 전부 논문에서 가져왔습니다

| 상수 | 출처 | 값 |
| --- | --- | --- |
| **종가속 한계** | Cui et al., **ICRA 2019** (DKM) — 제어 클리핑 각주 | **8.0** m/s² |
| **횡가속 한계** | Bahari et al., **CVPR 2022** — 식 6 `v²/R ≤ μg`, μ = 0.7 | **6.87** m/s² |
| **속도 바닥** | Phan-Minh et al., **CVPR 2020** (CoverNet) — `max(v, 1)` | **1.0** m/s |

> ⚠️ **처음엔 횡가속을 8.0 으로 뒀는데 근거를 못 댔습니다.** 같은 식을 쓴 논문 값이
> **6.87**(μ=0.7)이라 오늘 맞췄습니다. 좁혀도 표현력이 주는지 재 봤고 거의 안 움직였습니다.

**반대로 논문 근거가 없는 것도 둘 있습니다** — 저속 임계 `0.5 m/s`(우리 측정이 근거)와,
정지 차의 **방향 동결**(제 설계). 문서에 그렇게 적어 뒀습니다.

> 🔄 **그리고 설계를 하나 뒤집었습니다.** 원래는 *"정지 구간을 heading 채점에서도 뺀다"* 였는데,
> **그렇게 하는 선례가 하나도 없었습니다.** 포크 대상인 SIMPL 자신도 속도 게이트 없이 모든
> 스텝에 yaw 손실을 겁니다. 저자 ablation 으로는 **거의 공짜**였습니다 — minADE6 `0.780 → 0.783`
> 인데 최종 yaw 오차는 **−74%**(0.297 → 0.076). 그래서 **채점은 원본 그대로** 두고 동결은
> 적분기 안에서만 합니다. (코드는 처음부터 그랬고 **문서가 틀렸습니다.**)

## 4. 작업 현황

| 단계 | 바꾼 것 | 결과 |
| --- | --- | --- |
| 검증 | 없음 — 저자 가중치 재평가 | **0.777** ✅ 저자와 일치 |
| R0 | 없음 — 원본을 우리가 학습 | **0.795** ← 기준점 |
| R1 | **입력만** `(a, h)` | **0.830** ❌ 졌다 |
| R0-s43 | 시드만 42→43 | **0.801** ← 실험 아님, **자** |
| **R2** | **출력도** `(a, Δh)` + 적분기 | 🔄 **학습 중** (11-26 03:28 시작 · 46시간) |

- **R1 의 열세는 시드 폭(0.006)의 5.8배** 라 "운이 아니다" 는 넘었습니다. 왜 졌는지는 R2 가 가릅니다.
- **판정 규칙은 값을 보기 전에 못 박았습니다** — 결과 구간 다섯 개와 각각의 다음 수.
- **띄우기 전 확인 둘.** 적분기가 도달할 수 있는 바닥 **0.0135 m**(목표의 60배 아래) ·
  방향 정확도를 R0·R1 에서 먼저 재 둠.
- **새 후보** — R1 은 원본에 있던 **AV2 속도벡터 2칸**을 버렸습니다. 추적기가 걸러 준 신호라
  위치차분보다 3배 매끄럽습니다. *"왜 졌나"* 의 세 번째 용의자입니다.
