# AV2 heading 라벨 품질 — 전수 조사

작업일: 2026-09-03 · 스크립트: `src/check_heading_quality.py` · 표본: **전체 249,880 시나리오 / 25,737,880 step**

---

## 1. 왜 쟀나

v4 는 방향을 이렇게 분해한다.

```
h = k + θ      k = 차로(경로) 방향각,  θ = 차로 대비 차체 잔차각
```

모델은 절대각 대신 **작은 잔차 θ 만** 예측하면 된다. 그런데 heading 라벨이 튀면 θ 가
그대로 오염된다. AV2 논문([arXiv 2301.00493](https://arxiv.org/abs/2301.00493))이
motion forecasting 트랙을 자동 멀티센서 퓨전 결과라 하며 **"imperfect tracking"** 이라고
명시하고 있어, 실제로 얼마나 튀는지 전 데이터에서 확인했다.

## 2. heading 의 정의 (SDK)

```python
heading: Heading associated with object bounding box
         (in radians, defined w.r.t the map coordinate frame)
```

| 항목 | 내용 |
| --- | --- |
| 기준 | map(city) 좌표계 — 절대 방위각 |
| 0 rad | +x 방향, +π/2 = +y (반시계 양수) |
| 범위 | (−π, π] (실측 −3.1416 ~ +3.1416) |
| 의미 | **차체가 향한 방향** — 이동 방향이 아님 |

주행 중(3 m/s 이상) 실측: `|atan2(vy,vx) − h|` 중앙 **0.21°**, `|atan2(Δp) − h|` 중앙 **1.03°** / p95 9.86°.
velocity 와는 거의 일치하고 위치 차분과는 최대 10° 벌어진다 — 이 차이가 **슬립각**이다.
정지 구간(전체의 14.5%)에서도 heading 은 유지된다 (변화 최대값의 중앙 0.13°).

## 4. 결론 — v4 에 써도 되는가

**된다.** 근거:

- p99.99 가 **7.3°** 로, θ 의 실제 분포(±10° 안에 91.7%)를 덮지 않는다. 분해해도 신호 대 잡음비가 유지된다
- 30° 초과가 2,570만 step 중 **11건**(0.00004%)

**다만 가드는 넣는다.** 174° 뒤집힘이 실재하므로(1 시나리오), 전처리에서
**스텝당 |Δh| > 30° 이면 직전 값을 유지**하는 규칙을 둔다. 영향받는 시나리오가 0.0028%라
데이터 손실은 무시할 수 있고, 학습 중 한 샘플이 θ 를 크게 오염시키는 것은 막을 수 있다.

> 200개 표본만 봤을 때는 "튀는 값 0건"이었다. 전수로 봐야 174° 케이스가 나온다 —
> **드문 사건은 표본으로 확인할 수 없다**는 사례.
