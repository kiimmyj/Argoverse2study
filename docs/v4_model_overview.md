# v4 모델 설명 — 지도를 아는 궤적 예측

> Argoverse 2 Motion Forecasting · 노션용 · 2026-09-17 기준 (브랜치 `lane-rules`)
> 수치 출처와 실험 기록은 `docs/v4_notion.md`, 시각화 분석은 `docs/v4_viz_report.md`.

---

## 한 줄 요약

**v4 는 (a, h) 를 입력으로 받아, 지도에서 뽑은 후보 경로마다 (a, Δθ) 를 예측하고, 적분 함수로 궤적을 복원한다.**

- 함수는 **Frenet 적분기**다. 학습할 수 있는 파라미터가 없는 결정론적 함수라, 학습 때와 추론 때 쓰는 경로가 같다.
- **"어느 길로 갈지"는 지도**가 후보 경로로 주고, **"그 길에서 어떻게 움직일지"는 모델**이 액션으로 낸다.

```
h  =  k  +  θ          예측 모드 = 지도에서 뽑은 후보 경로 K = 6개
      ↑     ↑
   지도가   모델이
   준다     배운다
```

---

## 1. 데이터 전처리

### 1.1 진행 방향 h 를 직접 만든다

AV2 의 `heading` 은 **차체 방향**이라 실제 이동 방향과 **슬립각만큼 어긋난다**. 저속에서는 잡음이 크고 180° 뒤집힘도 있다.

| h 만드는 법 | 방향만 바꿔 궤적을 복원했을 때 최종 오차 |
| --- | --- |
| AV2 heading 그대로 | **1.693 m** |
| **위치 차분 + 1 m/s 미만만 AV2 로 채움** (채택) | **0.145 m** |
| 위치 차분만 | 0.000 m (저속에서 방향이 70~110°/s 로 튀어서 못 씀) |

- **h** = 차량 **이동 방향 각도**다.
  - 위치 차분으로 만든다.
  - 1 m/s 미만 저속 구간만 AV2 heading 으로 채운다. 이때 180° 뒤집힘과 한 스텝에 30° 넘게 튀는 값은 먼저 교정한다.
- **관측 구간(과거 5초)만 쓴다.** 차분은 다음 위치를 보기 때문에, 미래까지 넣으면 첫 예측 대상이 입력에 새어 들어간다.

### 1.2 방향 분해 — `h = k + θ`

| 기호 | 뜻 | 누가 주나 |
| --- | --- | --- |
| **h** | 차량 이동 방향 각도 | 위치 차분으로 직접 만든다 |
| **k** | **차로 중심선의 방향각(접선 각도)** — 후보 경로 위 거리 s 에서의 도로 방향 | **지도**가 준다 |
| **θ = h − k** | 도로 방향 대비 차가 틀어진 각 | **모델**이 배운다 |

- **곡률 κ [1/m] 과 k 는 다른 양이다.** κ 는 k 가 거리에 따라 바뀌는 정도다(dk/ds). 원래 설계는 곡률 레벨이었다. 하지만 각도 레벨로 올리면 적분이 한 단계 줄어, 작은 편향이 거리에 따라 커지지 않는다.
- **왜 나누나** — h 는 도로 방향 따라 360° 전체에 퍼져 있다. θ 는 0 근처에 몰려 있다(경로 기준 ±10° 이내 91.9%). 6초 동안 따라가야 할 변화량도 |Δh| p90 52.8° 에서 |Δθ| p90 14.6° 로 줄어, **방향 변화의 약 2/3 를 지도가 대신 설명한다.**

### 1.3 입력 (a, h) 와 2 Hz 다운샘플

| 채널 | 무엇 |
| --- | --- |
| **a** | 속도 증분 [km/h] ÷ 3. **첫 값에만 관측 시작 시점의 속도**를 싣고 나머지는 증분이다. 누적합하면 속도 곡선이 그대로 돌아온다 |
| **h** | 위 1.1 의 이동 방향(마지막 관측 시점 기준으로 회전·정규화) |

| 입력 | 형태 | 만드는 법 |
| --- | --- | --- |
| `ah2` (10 Hz) | 50 스텝 × 2 | 관측 위치에서 그대로 |
| **`ah2_2hz` (2 Hz)** | **10 스텝 × 2** | 위치를 **평활(Savitzky–Golay 0.5초)** 한 뒤 **0.5초 간격으로 뽑는다** |

- **왜 2 Hz 인가**
  - 10 Hz 위치 차분은 스텝당 변위가 수 cm 라 저속 잡음이 크다. 0.5초 간격이면 잡음 비중이 줄고 입력 길이도 50 → 10 으로 준다.
  - 평활은 **뽑기 전에** 건다. 뽑기만 하면 0.1초짜리 흔들림이 섞인다.
  - h 채널의 ±π 점프(방향이 180° 경계를 넘을 때 값이 튀는 것)도 1.65% → 0.50% 로 줄었다.
- **창 가장자리 램프를 뺀다** — AV2 위치 트랙은 11초 창의 **양 끝 0.5초**에서 속력이 실제의 절반쯤으로 찍힌다.
  - 움직이는 차량의 96% 가 이렇다. 창 단위 평활의 경계 효과로 보인다.
  - 2 Hz 입력은 이 앞부분(0~0.4초)을 평활에서 뺀다.
  - 정답 쪽 끝 0.5초의 가짜 감속은 모델이 그대로 배운다(시각화 리포트 발견 6).
- **바뀌는 것은 입력뿐이다.** 정답, 후보 경로, 적분기 시작값은 10 Hz 와 같다.
- **결과: 이득이 없었다.** 같은 조건의 10 Hz 판보다 최근 5에폭 평균 minADE6 가 6~7% 나빴고, 에폭 시간도 그대로였다. **기본 입력은 10 Hz** 다(`docs/v4_notion.md` 2.6절).

### 1.4 지도 → 주변 차로와 후보 경로

| 무엇 | 어떻게 |
| --- | --- |
| **주변 차로 20개** | 중심선 10점 + 규칙 피처 10개(진행 방향, 같은 방향 여부, 교차로, 차로 종류, 좌/우 차선변경 가능, 도달 가능) |
| **후보 경로 K = 6** | ① 현재 위치 5 m 안의 같은 방향 차로에서 출발한다. ② **successor 만** 이어 차로 사슬을 만든다(U턴 제외). ③ 관측 궤적과 가까운 순으로 정렬한다. ④ 6초 지평에서 2.5 m 안에 겹치면 같은 분기로 보고 버린다. ⑤ 구별되는 경로 R 개로 6칸을 돌려 채운다 |
| **경로 하나의 표현** | 호길이 등간격 64점의 좌표·접선·**허용 밴드**·길이, 그리고 현재 위치의 (s0, d0) |
| **경로가 없을 때** (val 3.6%) | 직진 가상 경로 1개 |

- **왜 successor 만인가** — 차선변경을 기하로 이어 붙이면 이음매가 접혀 θ 가 180° 뒤집힌다. 차선변경은 이웃 차로에서 시작하는 **별도 경로**나 **횡오프셋 d** 로 표현한다.
- 전처리 결과는 `prepare_v4.py` 가 **캐시**로 구워 둔다. 읽기가 원본보다 약 1,500배 빠르다.

## 2. 모델 구조 (원 설계에서 바뀐 것 반영)

```
[preprocessing]
  주변 차로 20개(좌표 + 규칙 피처) · 후보 경로 K=6(좌표·접선·밴드·길이) · 입력 (a, h)
        │
        ▼
  ┌──────────────────────────────────────────────┐
  │  인코더                                       │
  │    과거 (a, h)  50 step (10 Hz) / 10 step (2 Hz) │
  │    LSTM 2층 → 궤적 특징                        │
  │    + cross-attention ◄── 차로 토큰 20개        │  ◄── L2
  └────────────────────┬─────────────────────────┘
                       ▼
  ┌──────────────────────────────────────────────┐
  │  디코더  (모드 K=6개, 각각 독립)                │
  │    모드 = [인코더 특징, 경로 r 임베딩, 복제 번호]  │  ◄── L3
  │    출력: (a, Δθ) x 60 step  + 모드 확률        │
  └────────────────────┬─────────────────────────┘
                       ▼
  ┌──────────────────────────────────────────────┐
  │  적분기 f  (미분 가능, 누적합만 사용)            │
  │    v = v0 + Σ a·dt                            │
  │    θ = θ0 + Σ Δθ          (|Δθ| ≤ 8°/step)    │
  │    s = s0 + Σ v·cosθ·dt,  d = d0 + Σ v·sinθ·dt │  ◄── L0
  │    h = k_r(s) + θ     (k_r = 경로 r 의 방향각)  │
  │    p = 경로 r 중심선(s) + 법선 × d              │
  └────────────────────┬─────────────────────────┘
                       ▼
  ┌──────────────────────────────────────────────┐
  │  손실 (복원된 위치 p 와 액션에 건다)             │
  │    거리 손실(승자) + 모드 확률(CE)              │
  │    + 흔들림 벌점 (모든 모드)                    │  ◄── L0
  │    + 차로 이탈 벌점 (버려진 모드)               │  ◄── L4
  └──────────────────────────────────────────────┘
```

**원 설계 대비 바뀐 것**

| 원 설계 | 지금 | 왜 |
| --- | --- | --- |
| 입력 (a, kappa) | **(a, h)** (10 Hz 또는 2 Hz) | 방향을 각도 레벨로 통일. 곡률은 원시 중심선에서 잡음이 크다(p99 0.379 1/m) |
| 경로별 곡률 테이블 | **경로 접선 방향각 k** | 각도 레벨이라 적분 한 단계가 줄고 편향이 거리 따라 안 커진다 |
| 출력 (a, delta) | **(a, Δθ)** — θ 의 변화율, 스텝당 8° 상한 | θ 를 값으로 내면 궤적의 71% 가 실제 차가 못 내는 회전이었다 |
| kappa = kappa_lane(s) + delta | **h = k(s) + θ** | 위와 같음 |
| off-road 필드 (주행가능영역 SDF) | **경로 중심선 기준 밴드** | 도로 전체 기준이면 대향 차로도 '도로 안'이라 역주행을 못 막는다. SDF 전처리도 필요 없다 |
| 손실: 거리 + off-road | **+ 모드 확률(CE) + 흔들림 벌점(L0)**, 이탈 벌점은 **버려진 모드만** | 아래 3·4절 |

- 파라미터 수: **450,681** (2채널 입력 기준)

## 3. 레벨별 설명

| 레벨 | 무엇을 | 어떻게 | 왜 |
| --- | --- | --- | --- |
| **L2** | 지도 cross-attention | 궤적 특징이 query, 주변 차로 20개(좌표 + 규칙 피처)가 key/value | 모델이 주변 도로와 규칙을 보게 한다. 기준선 1.292 를 그대로 재현 |
| **L3** | 모드 = 후보 경로 | 모드마다 경로 하나를 조건으로 받아 궤적과 확률을 따로 낸다. 빈 칸은 확률 −∞ | 익명 모드는 갈림길에서 두 길의 **평균**을 낸다(T자에서 48° 비스듬히 가로지름). 다중 모드는 지도에 실제로 있는 이산 선택지여야 한다 |
| **L0** | 출력 = 액션 + Frenet 적분 + 흔들림 벌점 | 모델은 (a, Δθ) 만 내고, 적분기가 경로 위에서 s·d 를 적분해 위치로 바꾼다 | ① d 가 상태 변수로 바로 나와 L4 가 간단해진다. ② h = k + θ 가 정의대로 성립한다. ③ 순차 루프가 없어 학습·추론 경로가 같다 |
| **L4** | 차로 이탈 벌점 | L0 가 만든 d 가 밴드 밖으로 나간 만큼만 벌한다(버려진 모드만) | 거리 손실은 승자 하나만 감독한다. 나머지 5개 모드는 L4 가 없으면 아무 감독도 받지 않는다 |

**L0 의 두 가지 안전장치**

| 장치 | 없으면 | 있으면 |
| --- | --- | --- |
| Δθ 레이트 상한 8°/step | 7.3°/step(실제 차량 상한)을 넘는 step 71.4% | 0.4% |
| **흔들림 벌점** (L0 기본, 가중치 1.0) | 전체 데이터로 학습하면 θ·a 가 매 스텝 부호를 뒤집는 진동 — 7.3° 초과 35% | **0.08%** |

- 레이트 상한은 **크기만** 막고 진동은 막지 못한다.
- 진동은 위치를 수 cm 만 흔들어 거리 손실이 감독하지 못한다. 그래서 벌점을 따로 둔다.

## 4. 벌점 — 두 가지를 구분한다

| 벌점 | 레벨 | 무엇을 벌하나 | 어느 모드에 | 가중치 |
| --- | --- | --- | --- | --- |
| **흔들림** | **L0** | 액션 (a, Δθ) 의 이웃 스텝 차이의 제곱 — 각자 상한(8 m/s², 8°)으로 나눠 단위를 없앤다 | 살아있는 **모든** 모드(정답에 가장 가까운 모드도 진동했다) | 1.0 |
| **차로 이탈** | **L4** | 경로 중심선에서의 횡거리 d 가 **밴드 밖으로 나간 거리** | **버려진 모드만** | 1.0 |

### 차로 이탈 벌점의 기준 (L4)

- **기준선:** 모드마다 **자기 후보 경로(차로를 이어 붙인 길)** 위에서 적분된다. 그래서 매 스텝 그 중심선에서 좌우로 떨어진 거리 **d** 가 바로 나온다(L0 적분기의 상태 변수).
- **허용 폭(밴드):** 경로의 차로 구간마다 정해진다.

| 구간 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 기본 (자기 차로 안) | 1.75 m | 1.75 m |
| 규칙상 그쪽으로 차선변경 가능 | 3.6 m | 3.6 m (해당 쪽만) |
| 교차로 안 (코너를 크게 도는 것 허용) | 3.6 m | 3.6 m |
| 경로가 없는 시나리오(직진 가상 경로) | 3.6 m | 3.6 m |

- **벌점 = max(0, d − 왼쪽 폭) + max(0, −d − 오른쪽 폭)** 을 60스텝 평균한다. 밴드 **안에서는 어디에 있든 0** 이다.
- **한쪽만 벌하는 이유:** 중심으로 끌어당기면 편도 2차선 도로에서 중앙선이 최적해가 된다.
- **버려진 모드만 벌하는 이유:** 정답에 가장 가까운 모드는 거리 손실이 이미 감독한다. 게다가 정답 궤적조차 14% 의 스텝이 밴드를 넘어서, 거기에 걸면 잘못된 벌점만 는다.
- **도로 끝선이 아닌 이유:** 도로 전체를 기준으로 하면 대향 차로로 넘어가도 벌점이 0 이고, 큰 교차로는 어디든 '도로 안'이다.
- **한계:** 밴드 폭은 실제 차선 경계선이 아니라 고정값(1.75 / 3.6 m)이다.

## 5. 학습 설정과 현재 성적

- **손실:** 끝점 오차가 가장 작은 살아있는 모드를 승자로 잡는다. `smoothL1(승자 궤적) + CE(모드 확률) + 1.0·흔들림 + 1.0·이탈(버려진 모드)`
- **설정:** train 199,908 (전체) · 15 에폭 · lr 5e-4 · batch 32 · 시드 0.
  - 캐시로 읽어 에폭당 약 2분이다(train + val 24,988 평가).

| 모델 (val 24,988 재채점) | minADE6 | minFDE6 | 밴드 이탈 | 7.3° 초과 |
| --- | --- | --- | --- | --- |
| L4 (a, h) · train 5만 | 1.678 | 3.912 | 0.87 | 3.42% |
| L4 (a, h) · 전체 데이터 (벌점 없음) | **1.480** | **3.409** | **0.60** | 19.65% ← 진동 |
| **L4 (a, h) · 전체 데이터 · 흔들림 벌점** | 1.586 | 3.775 | 0.81 | **0.70%** |
| L4 (a, h) · 전체 데이터 · 흔들림 벌점 · 입력 2 Hz | 1.643 | 3.879 | 0.67 | 1.42% |

- **읽는 법:** 흔들림 벌점을 건 판이 5만 판보다 모든 지표에서 낫다. 벌점 없는 판은 정확도가 좋지만 실제 차가 못 내는 진동을 낸다.
- **minADE6 만으로 읽으면 안 된다:** 이 설계는 minADE 를 조금 내주고 실현 가능성과 규칙 준수를 사는 거래다. 기준선(v3 지도 모델 + 차로 규칙 피처, 위치 직접 회귀)은 1.292 다(val 2,000).
- **어디서 틀리나(시각화 분석):** 회전(좌회전 minADE6 2.74 m)이 가장 어렵다. 나쁜 시나리오는 주로 **후보 경로에 정답이 없는 경우**(최악 그룹 52.8%)와 **속도(종방향) 오차**에서 나온다.
