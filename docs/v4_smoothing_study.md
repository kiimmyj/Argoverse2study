# v4 전처리 평활(smoothing) 실험 — 무엇을 평활해야 하고, 무엇이 가장 잘 하나

- **무엇:** 전처리 = 평활 + 다운샘플. 다운샘플은 기계적이므로 **평활**만 후보 비교했다.
  1순위 기준은 사용자가 정한 대로 **직진 시나리오에서 heading vs 시간 그래프가 일관되게 유지되는가** 다.
- **데이터:** val 3,000 시나리오(시드 0으로 뽑은 표본, 정렬 순서 재현 가능).
  focal 3,000 트랙 · 관측 50스텝이 모두 있는 주변 차량 31,810 트랙. 원본 parquet 에서 직접 읽었다(캐시 미사용).
- **만든 명령**

  ```
  python src/smooth_study.py --task char   --limit 3000    # 1단계 데이터 특성
  python src/smooth_study.py --task eval   --limit 3000    # 2·3단계 후보 비교 (약 2분)
  python src/smooth_study.py --task cases  --limit 3000    # 대표 시나리오 덤프
  python src/smooth_study.py --task verify --limit 400     # 구현 검증 + 합성 신호
  python src/viz_smooth_char.py ; python src/viz_smooth_summary.py ; python src/viz_smooth_panels.py
  ```

- **산출물:** 그림 `viz/v4/smoothing/`(요약 3장 + 특성 3장 + 패널 21장), 숫자 `viz/v4/smoothing/data/{char,eval,cases,verify,recommend}.json`
- **학습·커밋 없음. 기존 파일은 import 만 했다.** 새 파일은 `src/smooth_study.py`, `src/viz_smooth_{char,summary,panels}.py` 뿐이다. GPU 미사용.

## 1. 정의

| 이름 | 정의 |
| --- | --- |
| **관측 구간** | 인덱스 0~49 (t = −4.9 … 0 s). 모든 후보는 이 50스텝만 본다. **인과성** = 스텝 50 이상(미래)을 보지 않는다는 뜻이고, 창 **안에서는** 양방향(zero-phase) 필터를 허용한다 — 지금 쓰는 SG(mode='interp')도 같다 |
| **지표 구간** | 인덱스 5~49. 창 시작 램프(0~4)를 뺀다(발견 6) |
| **h (진행방향)** | `heading_decomp.build_heading` 규약 그대로: 구간 속력 ≥ 1 m/s 면 위치차분 방향, 아니면 가드·뒤집힘 교정한 AV2 heading, 남으면 이웃값. 평활은 **h 를 만들기 전 위치에** 건다(방식 a) 또는 **h 에 직접** 건다(방식 b) |
| **독립 기준 course** | AV2 `velocity` 필드의 방향. 구간 중점 비교는 `atan2(v[t]+v[t+1])`. 위치와 별개 채널이라 위치 잡음·램프의 영향을 받지 않는다 |
| **직진 시나리오** | 속도필드 course 의 관측 구간 순 변화 \|Δcourse\| < 5° **그리고** 이동거리 > 10 m **그리고** 스텝 5~49 AV2 속력 최소 ≥ 1 m/s. n = 1,337 / 3,000 |
| **회전 시나리오** | \|Δcourse\| > 30°, 이동 > 10 m, 속력 최소 ≥ 3 m/s. n = 178 |
| **정지 차량** | 관측 50스텝 AV2 속력 **최대 < 0.3 m/s**. 주변 차량 18,744 대 |
| **① \|Δh\|** | 스텝 간 진행방향 변화를 **°/s 로 통일** (10 Hz 는 ÷0.1 s, 2 Hz 는 ÷0.5 s). 직진이므로 참값 ≈ 0 이고 값이 곧 잡음 크기다 |
| **① 추세제거 잔차 σ** | unwrap 한 h 에 1차 추세를 맞추고 뺀 잔차의 트랙별 표준편차 [°], 그 중앙값 |
| **① 지그재그** | Δh 의 부호가 직전 스텝과 뒤집힌 스텝 비율 [%]. 순수 백색이면 50%, 부드러운 회전이면 0% |
| **② 최대 요레이트 비** | max\|dh/dt\| ÷ max\|d(course)/dt\| (같은 트랙, 같은 구간). 1 이면 보존, <1 이면 깎임 |
| **② 순 회전량 비** | (h[49] − h[5]) ÷ (course[49] − course[5]). 최댓값 통계와 달리 **잡음에 둔감** 하다 |
| **② 요레이트 RMSE** | rms(dh/dt − d(course)/dt) [°/s]. 잡음(①)과 감쇠(②)를 한 숫자로 본다. 임계값이 없어 순위용으로 쓴다 |
| **③** | \|wrap(h − course_mid)\| [°], 속력 ≥ 1 m/s 인 스텝만, 램프 제외 |
| **④** | 평활 위치 − 원본 위치 RMSE [cm], 그리고 **방향만 바꿔 다시 굴린** 궤적의 끝점 오차(스텝 길이는 원본 사용) |
| **⑤** | 정지 차량에서 (a) 위치차분 속력이 1 m/s 를 넘는 스텝 비율 = 잡음이 만든 가짜 이동, (b) `align_ref` 가 그 트랙을 180° 뒤집는다고 판정한 비율 |
| **⑥** | 첫 스텝 속력 ÷ 스텝 10~15 평균 속력 (원본 평균 속력 > 3 m/s 인 focal 1,997대). 1 이 정상 |
| **⑦** | 평활 위치에서 만든 종방향 저크 \|j\| 와 요각가속 \|α\|. 사람 운전 범위는 \|j\| < 4 m/s³ |
| **⑧** | 평활 → 2 Hz 다운샘플(인덱스 4, 9, …, 49) 뒤 ①~③ 을 다시 잰 값. **지금 파이프라인과 같은 순서** |

**합성 ②가 중요한 이유:** 실데이터의 ②(최대 요레이트 감쇠)가 "신호를 깎은 것"인지 "잡음 봉우리를 없앤 것"인지 가른다.
잡음이 0 인 등회전에서 창 안쪽 요레이트가 정확히 1.000 이면, 실데이터의 감쇠는 잡음 쪽이다.

**한계로 남긴 것:** 운동학 제약 적합(`kin`)은 초기해에 민감하다. L-BFGS 가 세 초기해에서 서로 다른 점에 멈춘다
(가우스0.25 초기해 목적함수 2,738 / 원본 초기해 17,519 / 가우스0.40 초기해 3,860, val 600).
보고한 `kin` 은 그중 **목적함수가 가장 낮은** 해(가우스0.25 초기해)다.

**(a) 위치 잡음의 크기 — 두 방법이 횡방향에서 일치한다**

| 추정 방법 | 모집단 | 결과 |
| --- | --- | --- |
| 정지 차량 위치의 1차 추세 제거 잔차 | 주변 차량 18,744 | 종 **17.8 cm** · 횡 **6.9 cm** (rms 13.5 cm) |
| 같은 것, focal | focal 261 | 종 12.6 cm · 횡 2.4 cm (rms 9.1 cm) |
| 등속 직진(≥8 m/s, \|Δcourse\|<2°) 구간의 **직선** 적합 잔차 | focal 506 | 1차: 종 42.1 · 횡 10.2 cm — 종방향은 실제 속도 변화가 섞인다 |
| 같은 구간, **2차** 적합 잔차 | focal 506 | 종 20.9 · 횡 **6.9 cm** |

→ 서로 독립인 두 모집단에서 **횡방향 위치 잡음 ≈ 7 cm** 로 같다. 종방향 값이 큰 것은 실제 가감속이 섞이기 때문이다.

**(b) 잡음의 '색' — 평활이 지울 수 있는 것은 아주 작은 부분뿐이다**

- 정지 차량 스텝 변위: 중앙 **0.40 cm**, 1 cm 미만 **72.5%**, p99 **23.3 cm**, 1 m/s(=10 cm/스텝) 초과 **4.02%**.
- 잔차 자기상관: lag 1 **0.943**, lag 5 0.654, lag 10(1 s) **0.302**.
- 2계 차분에서 뽑은 **백색 성분** σ = **0.77 cm** (rms), 0.032 cm (MAD).

→ 잡음 = 상관시간 ~1 s 의 **저주파 흔들림 13.5 cm** + **백색 0.8 cm** + **두꺼운 꼬리(가끔 20 cm 이상 튐)**.
저주파 흔들림은 5초 창 안에서 실제 저속 이동과 구분할 방법이 없다 — **어떤 평활기도 이것은 못 지운다**(한계, 7절).
평활이 실제로 지우는 것은 백색 성분과 꼬리다. 그런데 그 둘이 heading 지그재그와 불가능한 저크를 전부 만든다.

**(c) 스펙트럼 — 갈리는 지점은 0.6~1.0 Hz**

창은 11초 중 인덱스 5~104(10 s, 100스텝), Hann, Δf = 0.1 Hz. 전처리는 50스텝만 쓰지만 **특성 측정**이라 주파수 해상도를 위해 긴 창을 썼다.

| 주파수 | 위치 진폭 5–10 m/s [m] | 위치 진폭 정지(=잡음) [m] | 비 |
| --- | --- | --- | --- |
| 0.2 Hz | 1.019 | 0.058 | 17.5 |
| 0.4 Hz | 0.093 | 0.047 | 2.0 |
| 0.5 Hz | 0.061 | 0.047 | 1.3 |
| 0.7 Hz | 0.027 | 0.023 | 1.2 |
| 0.9 Hz | 0.0057 | 0.0080 | **0.7** |
| 1.5 Hz 이상 | 0.001~0.002 | 0.001~0.002 | ≈ 1 |

속력 쪽은 더 분명하다 — 위치차분 속력과 AV2 속도 필드 속력은 **0.8 Hz 까지 10% 안쪽으로 같고**(0.091 vs 0.081 m/s),
그 위에서 갈린다: 1.2 Hz 0.081 vs 0.030, 1.8 Hz 0.056 vs 0.011 (5배).
진행방향 진폭은 속력에 반비례한다(0.5 Hz 에서 1–5 m/s 5.5° vs 10–15 m/s 0.35°) — **저속일수록 방향 잡음이 크다**.

→ **−3 dB 컷오프를 0.5~0.9 Hz 에 두는 것이 이 데이터에 맞는다.** 가우시안이면 σ = 0.13/f_c → 0.15~0.25 s.

**(d) AV2 속도 필드** — 1 m/s 이상에서 위치차분 방향과 중앙 0.5~2.3° 로 맞고, 속력 크기도 1.002~1.009 배로 맞는다.
**1 m/s 미만에서는 둘 다 의미가 없다**(차이 중앙 37~81°) — 이 구간의 '기준'은 AV2 heading(차체)뿐이고 그건 다른 양이다.

**(e) 창 가장자리** — 위치차분 속력 ÷ 속도필드 속력 중앙값이 스텝 0~5 에서 0.505 → 1.002 로 오르고 끝에서 대칭으로 내린다.
**인덱스 5 부터 정상**이다(지금 코드의 `RAMP_SKIP=4` 는 비율 0.93 인 인덱스 4 를 포함한다).
2 Hz 는 첫 구간이 인덱스 4→9 의 평균이라 램프가 거의 상쇄된다 — 2 Hz 에서 램프는 큰 문제가 아니다.

1차 잔차 표준편차 13.5 cm 를 쓰면 저주파 흔들림까지 '지울 수 있는 잡음'으로 착각해 과평활이 된다.
속도 필드 잡음 σ_vel = **0.02 m/s** 는 정지 차량의 속도 필드 성분 표준편차다.
제약적합의 위치항은 **Huber(무릎 3σ)** 다 — 잡음이 정규분포가 아니라서(72.5%가 1 cm 미만, 4%가 10 cm 초과)
제곱 손실이면 그 4% 가 적합을 끌고 가 제약을 못 지킨다(실측: 위반 6~9% → Huber 로 0.97%).

**방식 (b) 의 정지 구간 규칙 (명시):** 평활은 `src == 1`(위치차분으로 정해진 = 실제 이동) 스텝이 **7스텝 이상 연속**인
구간 **안에서만** 한다. 그 안에서 unwrap → 평활 → wrap. `src != 1`(정지·AV2 보조·이웃값) 스텝과 7스텝 미만의
짧은 이동 구간은 **그대로 둔다** — 정지 구간 값은 AV2 차체 방향이고, 이웃 이동 구간과 섞으면 잡음이 정지 구간으로 번진다.

**왜 불가능한가:** ②의 '최대 요레이트'는 4.5초 창의 **최댓값** 이라 잡음에 그대로 오염된다.
기준선의 max\|dh/dt\| 자체가 잡음 봉우리이므로, 잡음을 지우면 정의상 ②가 떨어진다.
아래 셋이 그것을 보여준다.

1. 잡음 0 인 **합성 등회전**에서 가우스0.25/0.40 은 창 안쪽 요레이트를 **정확히 1.000** 로 보존한다(2절).

   컷오프 0.5 Hz 는 실제 회전 성분을 거의 건드리지 않는다.

**2차 규칙(1차가 빈 집합이라 결과를 보고 정했다 — 그래서 확증이 아니라 순위 매김에만 쓴다):**

## 6. 권고

### 1순위 — 가우시안 커널 σ = 0.25 s, 경계 2차 다항 외삽 (`g025q`)

```
σ = 0.25 s = 2.5 스텝(10 Hz) · 3σ 절단 → 17탭 · 커널 정규화
경계: 앞/뒤 9점에 2차 다항을 맞춰 8칸 외삽한 뒤 합성곱
적용: 인덱스 4~49 (RAMP_SKIP = 4 그대로). 램프(0~3)는 평활 창에도 넣지 않는다
순서: 평활 → 2 Hz 다운샘플(인덱스 4, 9, …, 49)   ← 지금과 같다
```

램프를 평활 창에 넣으면 안 되는 이유(실측, val 3,000 focal):

| 적용 범위 | 2 Hz ① p90 [°/s] | ⑦ \|j\|<4 [%] | 2 Hz 첫 표본 ÷ 속도필드(인덱스 4~9) |
| --- | --- | --- | --- |
| 인덱스 0~49 전체 | 2.65 | 83.7 | 0.971 |
| **인덱스 4~49 (권고)** | 2.68 | 87.2 | 1.032 |
| 인덱스 5~49 | 2.63 | 88.6 | 1.021 |

램프의 불가능한 가속도(스텝 0 에서 \|a\| 중앙 9.5 m/s²)가 커널을 타고 인덱스 5~10 으로 번지기 때문이다.
4 와 5 중 어느 쪽이든 차이는 작다 — 인덱스 4 는 2 Hz 가 뽑는 시점이라 4부터 평활하는 쪽(지금과 같은 규약)을 권고한다.

왜 이 값인가 — 전부 우리 데이터 숫자다.

- **왜 σ = 0.25 s 인가.** 가우시안의 −3 dB 주파수는 0.1325/σ 다. σ=0.25 → **0.53 Hz**.
  1단계 스펙트럼에서 이동 차량 위치 진폭이 정지 차량(순수 잡음)과 같아지는 지점이 0.6~1.0 Hz 이고,
  0.5 Hz 에서 이미 SNR 1.3 까지 내려온다. 컷오프를 그 바로 아래에 두면 신호가 이기는 대역만 남는다.
  σ=0.15(0.88 Hz)는 잡음을 절반밖에 못 지우고(저크 p90 11.3), σ=0.40(0.33 Hz)은 신호 대역을 파고들어
  순 회전량을 5.5%p 잃고 위치를 13.8 cm 옮긴다(실측 위치 흔들림 13.5 cm 와 같은 크기 — 더 가면 근거가 없다).
- **왜 2차 외삽 패딩인가.** 관측 창의 끝(t=49)이 곧 **예측 시작점**이고, 적분기의 θ₀ 가 여기서 나온다.
  1차(등속) 패딩은 잡음 0 인 등회전에서 창 끝 요레이트를 **0.327 배로 죽인다**. 2차 패딩은 **0.987** 로 살린다.
  실데이터 지표는 둘이 거의 같다(① 3.10 vs 3.25 °/s, ⑦ 83.4 vs 83.7%) — 즉 **공짜로 얻는 개선**이다.
- **왜 SG 가 아닌가.** SG(5,2)는 2 Hz 에서 무효과(발견 1)다. 창을 키워도 가우시안만큼 못 지운다 —
  가장 큰 SG(11,2) 도 2 Hz ① p90 3.13 (가우스 0.25 2차패딩 2.68), 저크 \|j\|<4 75.0% (83.7%) 에 그치고,
  창 끝 등회전 보존은 0.976 으로 오히려 가우시안 2차패딩(0.987)보다 낮다.
- **왜 Butterworth 0.5 Hz 가 아닌가.** 성능은 비슷하지만(① 2.59, ⑦ 88.5%) 짧은 창에서 경계가 불안정하다:
  잡음 0 인 등속 직선이 0.60 cm 휘고(패딩 30스텝으로 이미 줄인 값), 등회전 창 끝 보존이 0.221 이다.
- **왜 스플라인·칼만(위치만)이 아닌가.** 합성 신호 보존은 최고지만(스플라인 0.5 s 는 등회전 0.999) 실데이터 잡음 억제가 약하다
  (스플0.5s ① 4.32, 칼만CA ① 4.28 — SG(9,2) 수준). 매듭·모델이 잡음의 두꺼운 꼬리를 그대로 통과시킨다.
- **왜 운동학 제약 적합이 아닌가.** 수렴한 해는 가우스 σ=0.25 와 지표가 거의 같다(① 3.10 vs 3.10, ⑦ 83.1 vs 83.4).
  즉 **실측 잡음 + 사람 운전 한계로 세운 MAP 적합이 가우시안 σ≈0.25 s 와 같은 대역폭에 도달한다** — 1순위의 독립 근거다.
  하지만 초기해에 민감하고(2절) 시나리오당 최적화라 30배 느리다. 실무는 커널이 낫다.

**기대 효과(2 Hz 입력 기준, 지금 대비):** 직진 \|Δh\| p90 3.23 → 2.68 °/s(−17%), 지그재그 36.6 → 30.9%,
저크 p90 24.7 → 6.9 m/s³, \|j\|<4 비율 61.5 → 87.2%, 정지 차량 가짜 이동 3.83 → 2.90%, 뒤집힘 판정 6.73 → 5.45%,
요각가속 p90 71 → 18 °/s². 2 Hz 첫 표본은 속도 필드 대비 1.032 배로 램프 보정도 유지된다.
대가: 입력 위치가 원본에서 6.9 cm 이동(정답 y 는 안 건드림), 회전 순 회전량 0.926 → 0.911(−1.5%p).

### 2순위 — 칼만(CA) + RTS, 관측 = 위치 **+ AV2 속도 필드** (`kf_ca_v`)

```
상태 [x, y, vx, vy, ax, ay],  F = 등가속,  q_jerk = 4 m/s³
관측 = (x, y, vx, vy),  R = diag(σ_pos², σ_pos², σ_vel², σ_vel²)
σ_pos = 0.0077 m (정지 차량 2계 차분의 백색 성분),  σ_vel = 0.02 m/s (정지 차량 속도 필드 표준편차)
```

이 계열만 할 수 있는 것: **창 시작 램프를 실제로 고친다**(첫 스텝 속력비 0.476 → **0.895**),
정지 차량 가짜 이동 4.02 → **1.50%**, 180° 뒤집힘 판정 6.88 → **2.92%**(= 정지 차량 방향 오류의 절반이 사라진다).
2 Hz ① p90 도 3.23 → 2.40 으로 1순위보다 좋다.

**감당해야 하는 것:** 입력 위치가 원본에서 15.8 cm 움직인다(④). 지금 파이프라인은 입력 위치와 정답 위치가
같은 궤적에서 나오므로, 이 방법은 그 일치를 깬다(정답 y·경로·h0 는 그대로 두면 되지만 설계 결정이 필요하다).
그리고 ③·ωRMSE 의 개선은 순환논리라 근거로 못 쓴다(5절).
**CTRA 판(kf_ctra_v)은 쓰지 마라** — EKF 가 발산한다(위치 RMSE 75 cm, ωRMSE 189 °/s).

### 3순위 — 진행방향 unwrap 직접 평활을 위에 얹기 (`ang_*`)

```
h = build_heading(평활 위치) → src==1 이 7스텝 이상 연속인 구간마다 unwrap → SG(9,2) → wrap
src != 1 (정지·AV2 보조·이웃값) 과 7스텝 미만 이동 구간은 건드리지 않는다
2 Hz 에서는 같은 규칙을 SG(5,2)·최소 5스텝으로 적용
```

위치를 **전혀 안 건드리고**(④ RMSE 0) 2 Hz ① p90 을 3.23 → **2.55**, 지그재그 36.7 → **27.4%** 로 줄인다.
1·2순위와 겹쳐 쓰면 2 Hz ① p90 이 2.21(가우스0.25 위) · **1.91**(칼만CA+속도 위)까지 내려간다 — 전체 최저다.
h 채널만 고치고 a 채널(저크)은 안 고치므로 **단독으로 쓰지 말고 위치 평활 위에 얹어라**.

### 안 바꿔도 되는 것

- **다운샘플 순서**(평활 → 다운샘플)는 지금이 맞다. 다운샘플만으로도 ① p90 이 6.04 → 3.23 °/s 로 절반이 된다.
- **`RAMP_SKIP=4`** 는 그대로 두는 것이 낫다. 2 Hz 첫 표본은 속도 필드 대비 1.03 배로 이미 거의 편향이 없고
  (평활 없음 1.030 · SG(5,2) 1.030 · 가우스0.25 idx4~ 1.032), 램프를 평활 창에 넣으면 0.97 로 내려간다.
- **V_MIN = 1.0 m/s, JUMP_DEG = 30°, align_ref** 는 이 실험에서 안 건드렸다.

## 7. 한계

0. **평활로 못 고치는 큰 잔여 결함이 하나 더 있다 — `V_MIN` 전환.** 속력이 1 m/s 를 오르내리는 구간에서
   h 의 출처가 위치차분 ↔ AV2 heading 사이를 오가며 **한 스텝에 ±150 °/s** 짜리 계단이 생긴다
   (패널 `panel_급가감속_1.png`, `panel_저속 직진_*.png` 에서 분홍 띠 경계와 정확히 겹친다).
   평활기는 위치만 바꾸므로 이 계단을 못 없앤다 — 방식 (b)의 각도 평활도 `src != 1` 구간을 일부러 안 건드리므로 마찬가지다.
   **다음 과제:** 전환을 하드 스위치가 아니라 속력에 따른 가중 혼합(또는 칼만 상태 안에서의 융합)으로 바꾸는 것.
   이 실험 범위 밖이라 재지 않았다.
1. **저주파 위치 흔들림(σ 13.5 cm, 상관시간 ~1 s)은 어떤 평활기도 못 지운다.** 5초 창 안에서 실제 저속 이동과
   구분할 정보가 없다. 정지 차량 방향 오류가 완전히는 안 없어지는 이유다(가장 좋은 방법도 뒤집힘 판정 2.92% 남는다).
2. **모델 성능으로 검증하지 않았다.** 학습 금지 범위라 여기 숫자는 전부 전처리 신호 품질이다.
   minADE/FDE 가 실제로 좋아지는지는 감독 세션이 캐시를 다시 구워 확인해야 한다.
3. **회전 모집단이 작다(n=178).** \|Δcourse\|>30° · 속력≥3 m/s 조건 때문이다. ② 숫자의 신뢰구간은 넓다.
4. **운동학 제약 적합은 전역 최적이 아니다**(2절). 초기해마다 다른 점에 멈춘다. 보고값은 목적함수가 가장 낮은 해다.
   속도 필드 항을 넣은 판(`kin_v`)은 L-BFGS 가 배치에서 수렴하지 않아 뺐다.
5. **주변 차량은 ⑤(정지)만 재고 ①~④·⑥⑦ 은 focal 로만 쟀다.** 주변 차량은 관측이 끊기는 트랙이 절반이라
   같은 모집단으로 묶기 어려웠다. 주변 차량 heading 캐시에 같은 평활을 적용할 때는 다시 재야 한다.
6. **σ 를 0.15 / 0.25 / 0.40 s 세 점에서만 봤다.** 0.30~0.35 s 가 더 나을 수 있다 — 권고 전 확인할 값이다.
7. **2 Hz 지표 ⑧에서 각도 직접 평활 계열은 평활을 두 번 받는다**(10 Hz 위치 + 2 Hz 각도). 다른 계열과
   완전히 대등한 비교는 아니다. 파이프라인으로서의 비교로는 맞다.
