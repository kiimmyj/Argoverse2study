# Argoverse2study — 차량 움직임을 어떤 표현으로 기술해야 예측이 쉬워지는가

Argoverse 2 Motion Forecasting 위에서 **하나의 질문**을 재는 연구 저장소다.

> **차량의 움직임을 좌표 (x, y) 대신 (가속 a, 진행방향 h) 로 기술하면 예측이 쉬워지는가?**

좌표는 "어디에 있었나"를 적고, (a, h) 는 "무엇을 했나"를 적는다. 뒤쪽이 **회전에 불변**이고
도로 위 거동과 더 가까우니 모델이 배우기 쉬울 것이라는 가설이다. 이 저장소는 그 가설을
**한 번에 하나씩만 바꿔** 확인한다.

---

## 지금 어디까지 왔나

**SIMPL**(HKUST, MIT 라이선스)을 포크해 입력 표현만 갈아 끼우는 사다리를 올라가고 있다.
클론은 저장소 밖 `~/av2_simpl` 이고, 여기에는 **분석·측정·문서**가 들어 있다.

| 단계 | 무엇을 바꾸나 | 결과 (val minADE6) |
| --- | --- | --- |
| **검증** | 아무것도 — 저자 배포 가중치를 우리 경로로 재평가 | ✅ **0.777** (저자 보고치와 일치) |
| **R0** | 아무것도 — 원본 SIMPL 을 우리 장비에서 | ✅ **0.795** |
| **R1** | **입력만** (a, h) 11채널 | ✅ **0.830** |
| **R0-s43** | **시드만** 42→43 · 사다리가 아니라 **자** | ✅ **0.801** |
| **R2** | **출력도** 움직임 표현 + 고정 적분기 | 설계 승인, 착수 전 |

**R1 은 졌다.** 그런데 그 열세(+0.035)가 **시드만 바꿔서 생긴 폭(+0.006)의 5.8배**라,
"(a, h) 탓" 이라고 말할 수 있는 **필요조건**은 넘었다. 정착 구간 9점에서 두 띠가 겹치지 않는다.

**왜 졌는지는 둘로 갈렸고, 하나는 지웠다.** val 전수를 주변 차 입력 품질로 쪼개 재 보니
보조비율은 아무 신호도 들고 있지 않았다(이동거리를 통제하면 효과가 사라진다). 남은 것은
**표현 자체**이고, R2 가 그걸 *"표현이 나쁜가"* 와 *"반쪽만 바꿔서 나빴나"* 로 다시 가른다.

## 이 저장소가 지키는 규칙

연구 저장소라 결과보다 **결과를 믿을 수 있게 만드는 장치**가 많다. 코드를 읽기 전에 알아 두면
왜 이렇게 생겼는지 이해가 빠르다.

**① 숫자는 손으로 쓰지 않는다.** 문서의 수치는 생성기가 로그에서 읽어 `<!-- NUMBERS -->`
구간을 갈아 끼운다. 손으로 적을 자리를 남겨 두면 갱신될 때 한쪽이 낡는다.

**② 끝점이나 짧은 창으로 추세를 읽지 않는다.** 이 함정에 다섯 번 빠졌고 다섯 번 다
교차검증에서 잡혔다. 가장 선명한 증거: **같은 프로그램을 시드만 바꿔도 10에폭 창에서
"에폭당 3분" 짜리 가짜 효과가 만들어진다.** 그래서 계산을 `gap_shift()` · `drop_noise()` ·
`settled_band()` 로 옮겨 끝점을 아예 인자로 받지 않게 했다.

**③ 경계는 상수가 아니라 규칙이다.** "맞대는 구간과 **같은 구간**의 잡음". 그리고 끝점
판정에 쓸 자는 **런 간 폭**(같은 프로그램을 시드만 바꾼 차이)뿐이다.

**④ 판정 기준은 데이터를 보기 전에 못 박는다.** 값을 보고 정하면 사후 해석이다.

**⑤ 시드가 둘이면 표본은 하나다.** 쓸 수 있는 표현은 *"~보다 크다 / 구별되지 않는다"* 까지고,
*"확립했다"* 는 쓰지 않는다.

## 돌려 보기

```bash
conda activate av2
```

| 하려는 것 | 명령 |
| --- | --- |
| SIMPL 세 런 비교 (수치·그림·문서 갱신) | `python src/analyze_simpl_runs.py` |
| Frenet 기준선 두 규칙 전수 측정 | `python src/measure_frenet_baseline.py` |
| 입력 품질 분리 측정 합치기 | `python src/analyze_quality_split.py` |
| 회전 장면에서 기준선 두 규칙 그림 | `python src/viz_meeting_1029.py --only m7` |

**그림은 깃에 안 들어간다**(`.gitignore` 의 `*.png`). 생성기만 올리고 각자 다시 그린다 —
코드가 바뀌면 그림도 같이 갱신되라고 그렇게 뒀다.

데이터는 `/data/argoverse2` 아래에 있고 저장소에 포함되지 않는다.

## 앞선 작업 (v1~v4)

SIMPL 포크 이전에 자체 모델을 네 번 만들었다. 마지막 v4 는 근거가 확인된 구성요소 넷
(평활 · cleansing · lane-yaw · 주변 차량)을 다 쌓았는데도 기준보다 **나빴고**, 더 큰 벽은
기하였다 — 후보 경로 집합의 **오라클 경로조차 정답에서 평균 1.079 m** 떨어져 있어 당시
minADE6 와 같은 자릿수였다. 그래서 접고 공개 SOTA 를 포크하는 쪽으로 갔다.
자세한 경위는 [`docs/v4_restart_simpl.md`](docs/v4_restart_simpl.md) 에 있다.
